* ROM desc. = String that will appear on the menu
* ROM file  = Binary file of the ROM
* ROM start = Starting address of ROM. If begins with "$",
*             it is a hexadecimal address
* VIA       = Address that the VIA chip is located. If
*             begins with "$" it is a hexadecimal address
* I/O:6551  = Address were the I/O is located. 0 means no
*             IO. If there is a ":", this specifieds the
*             location of the 6551 chip. If this is not
*             specified, it will be 16 bytes above the
*             I/O starting address. If this begins with
*             "$", it is a hexadecimal address
* ROM RO    = If there is a sixth value, this specifieds
*             that the rom is read only. This can be any
*             value. I just needs to exist
*
* ROM desc.    ,ROM file       ,ROM start    , VIA ,I/O:6551
